# LuoKeeper

LuoKeeper — 二游账号管理工具，支持原神、崩坏：星穹铁道、绝区零、崩坏3（国服/国际服）与终末地的账号本地备份与快速切换，免重复扫码登录。

> **介绍视频**：[B站 BV1dN9CBjE1R](https://www.bilibili.com/video/BV1dN9CBjE1R/)

## 功能

- **账号备份与恢复** — 一键备份/恢复游戏登录凭证，切换账号无需重新扫码
- **快速启动** — 右键「快速启动」，自动恢复账号 → 启动游戏 → 自动重新备份
- **批量启动** — 多账号一键排队启动，支持并行/串行模式，进度窗口实时显示每个账号的启动状态
- **全自动委托** — 按游戏自动调用对应自动化工具完成每日委托：
  - **崩铁** → 三月七小助手（March7th Assistant）
  - **原神** → BetterGI
  - **绝区零** → OneDragon 一条龙
  - 每账号独立委托配置，实时日志查看 + 运行完成日志汇总
- **跨游戏委托** — 崩铁/原神/绝区零排序连刷，一个队列按序跑完多个游戏的日常
- **多选操作** — Ctrl 多选账号，批量加入/移出队列、批量启动、批量删除
- **自动重新备份** — 恢复后自动检测凭证时效，过期自动重新备份，间隔可配置
- **实时账号守护** — 运行期间自动检测当前游戏登录的账号，若不在备份列表中则自动创建临时备份，防止忘记备份导致账号丢失；手动备份后临时备份自动清除，每个游戏可单独开关
- **修改备份时间** — 右键修改备份时间戳，灵活管理备份有效期
- **崩铁多开解锁** — 一键解锁/恢复多开限制
- **崩铁 120FPS** — 一键开启/关闭游戏 120 帧
- **清除登录频繁限制** — 一键解除登录频次限制提示
- **多游戏支持** — 原神/崩铁/绝区零/崩坏3 × 国服/国际服 + 终末地，点击标题栏一键切换
- **主题系统** — 浅色/深色/自定义主题，多款预设
- **中英双语** — 底部按钮一键切换，即时生效
- **账号头像** — 内置 114 款头像可选
- **右键菜单** — 重新备份、重命名、自定义脚本、打开备份目录、打开密码文件、创建桌面快捷方式等
- **纯本地运行** — 备份与配置全部保存在本机，无云端上传

## 使用说明

### 基本使用

1. 启动软件，选择主题
2. 在设置中配置游戏启动器路径（支持自动检测）
3. 登录游戏后，输入名称点击「备份当前账号」
4. 切换账号时，选中账号点击「恢复选中账号」
5. 也可右键「快速启动」，一键恢复+启动+自动重备
6. 多账号批量切换：Ctrl 多选账号 → 右键「加入批量队列」→ 右键「开始批量启动」，进度窗口显示每个账号的状态，可暂停/继续

### 全自动委托

1. 在设置中配置自动化工具路径：
   - 崩铁：`March7th Assistant.exe`（三月七小助手）
   - 原神：`BetterGI.exe`（BetterGI）
   - 绝区零：`launcher.exe`（OneDragon 启动器）
2. 右键账号 → 「委托配置...」，为每个账号设置专属配置
3. 将账号加入批量队列后，右键「批量全自动委托」开始执行
4. 运行期间可查看实时日志，完成后展示日志汇总

> ⚠ 使用第三方自动化工具可能违反游戏协议，存在封号风险，请自行评估。

## 注意事项

- 备份文件包含登录凭证，请妥善保管，不要分享给他人
- 账号凭证有效期约 3 天，建议开启「自动重新备份」与「实时账号守护」
- 全自动委托需要以管理员权限运行
- 崩铁委托要求游戏分辨率为 1920×1080 窗口化
